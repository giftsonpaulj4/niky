Step 1: Set Up Jenkins Using Docker Compose 
  Create the project directory and the compose file (see Sample Inputs), then start Jenkins: 
 
    mkdir ~/jenkins-reactive-site 
    cd ~/jenkins-reactive-site 
    docker compose up -d 
 
  Get the initial admin password and open http://localhost:8080 to finish setup: 
    docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword

Step 2: Install the HTML Publisher Plugin 
  Open Manage Jenkins > Plugins, install 'HTML Publisher', and restart Jenkins if required. 
 
Step 3: Allow JavaScript in Published Reports 
  By default Jenkins blocks JavaScript in published reports. Open Manage Jenkins > 
  Script Console and run: 
 
    System.setProperty("hudson.model.DirectoryBrowserSupport.CSP", "") 
 
  This setting lasts until Jenkins restarts; run it again after a restart. 
 
Step 4: Create the Jenkins Pipeline Job 
  Click New Item, select Pipeline, name it 'karunya-reactive-site', and choose 
  'Pipeline script' as the definition. 
 
Step 5: Add the Pipeline Script 
  Paste the pipeline script given in Sample Inputs (it creates index.html, style.css and 
  app.js, publishes the site, and archives it) and click Save. 
 
Step 6: Execute the Pipeline 
  Click Build Now and wait for a successful build. Then click 
  'Karunya University - Reactive Site' in the left menu. 
 
Step 7: Observe the Reactive Behaviour 
  Click the 'Update Content' button and observe that the text changes without 
  reloading the page. 
 
Sample Inputs 
 
[A] docker-compose.yml -------------------------------------------------------------------------------- 
version: '3.8' 
 
services: 
  jenkins: 
    image: jenkins/jenkins:lts 
    container_name: jenkins 
    restart: unless-stopped 
    ports: 
      - "8080:8080" 
      - "50000:50000" 
    volumes: 
      - jenkins_home:/var/jenkins_home 
      - /var/run/docker.sock:/var/run/docker.sock 
 
volumes: 
  jenkins_home: 
    driver: local --------------------------------------------------------------------------------

[B] Jenkinsfile (Pipeline script) -------------------------------------------------------------------------------- 
pipeline { 
  agent any 
  stages { 
    stage('Generate Reactive Site') { 
      steps { 
        script { 
          def year = sh(script: 'date +%Y', returnStdout: true).trim() 
          sh 'rm -rf site || true' 
          sh 'mkdir -p site/assets' 
 
          writeFile file: 'site/index.html', text: """<!doctype html> 
<html lang="en"> 
<head> 
<meta charset="utf-8"/> 
<meta name="viewport" content="width=device-width, initial-scale=1"/> 
<title>Karunya University - Reactive Site</title> 
<link rel="stylesheet" href="assets/style.css"/> 
</head> 
<body> 
<header class="site-header"> 
<div class="container"> 
<h1>Karunya University</h1> 
<p class="tagline">Values - Knowledge - Service</p> 
</div> 
</header> 
 
<main class="container"> 
<section class="card"> 
<h2 id="about-title"></h2> 
<p id="about-text"></p> 
<button onclick="updateContent()">Update Content</button> 
</section> 
</main> 
 
<footer class="site-footer container"> 
<p>&copy; ${year} Karunya University - Generated by Jenkins</p> 
</footer> 
<script src="assets/app.js"></script> 
</body> 
</html> 
""" 
 
          writeFile file: 'site/assets/style.css', text: """ 
body { font-family: Arial, sans-serif; margin:0; } 
.container { max-width:800px; margin:0 auto; padding:20px; } 
.site-header { background:#0b3d91; color:#fff; padding:20px; } 
.card { background:#fff; border:1px solid #ddd; padding:15px; border-radius:6px; }

.site-footer { text-align:center; font-size:12px; color:#555; margin-top:20px; } 
button { padding:8px 12px; cursor:pointer; } 
""" 
 
          writeFile file: 'site/assets/app.js', text: """ 
let state = { 
  title: "About Karunya University", 
  description: "Karunya Institute of Technology and Sciences is a leading centre for higher 
education in India." 
}; 
 
function render() { 
  document.getElementById("about-title").innerText = state.title; 
  document.getElementById("about-text").innerText = state.description; 
} 
 
function updateContent() { 
  state.description = "This content was updated dynamically without page reload!"; 
  render(); 
} 
 
document.addEventListener("DOMContentLoaded", render); 
"""

    stage('Publish Site') {
